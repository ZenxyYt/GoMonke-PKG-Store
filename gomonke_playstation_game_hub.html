How PKG Files Work on Jailbroken PS4s

GoldHEN Package Installer Instructions

Jailbreak Prerequisite

Your PS4 must be running a jailbreakable firmware version (such as 9.00 via USB exploit or 11.00 via PPPoE) with GoldHEN enabled. GoldHEN unlocks the system's package installer functionality.

Prepare Your USB Drive

Format a USB flash drive to exFAT or FAT32. Place your downloaded `.pkg` files directly in the root directory of the USB drive (or inside a folder).

Install via GoldHEN

Plug the USB drive into your PS4. On your PS4 home menu, go to Settings > Game Installer (or open GoldHEN menu and select Package Installer). Select your `.pkg` file to install it directly to your internal hard drive or extended storage.
